# Guide des méta-tags Suno

> Utilise ce guide pour écrire (ou réécrire) les paroles de ma chanson avec des méta-tags Suno : un tag de structure au début de chaque section, complété par 2 à 4 tags de style, et une ligne de styles musicaux à coller dans le champ « Styles » de Suno.

## Que sont les méta-tags ?

Les méta-tags sont des instructions **entre crochets** intégrées directement dans les paroles, par exemple [anthemic chorus | stacked harmonies]. Ils indiquent à Suno comment chaque section doit sonner :

- **Style de chant** : rauque, autotuné, émotionnel…
- **Instrumentation** : solo de guitare, 808, cordes orchestrales…
- **Mixage** : largeur stéréo, réverbération, égalisation…
- **Dynamique** : montées, descentes, breakdowns…

## 1. Tags de structure (toujours les utiliser)

[Intro] · [Verse] · [Pre-Chorus] · [Chorus] · [Bridge] · [Build] · [Drop] · [Breakdown] · [Outro]

## 2. Tags vocaux

| Tag | Effet |
| --- | --- |
| [raspy lead vocal] | Voix avec du grain et de la texture |
| [autotuned delivery] | Traitement moderne hip-hop / pop |
| [stacked harmonies] | Chœurs superposés |
| [anthemic chorus] | Refrain puissant, prêt pour les stades |
| [spoken word verse] | Couplet parlé / rappé |
| [emotional build-up] | Intensité croissante |
| [crowd-style vocals] | Chant de foule, chant de groupe |

## 3. Tags instrumentaux

| Tag | Effet |
| --- | --- |
| [guitar solo] | Solo de guitare |
| [808 sub bass] | Basses trap / hip-hop |
| [60s jangly guitar rhythm] | Rock vintage |
| [sidechained synth bass] | Basse « pumping » EDM |
| [pedal steel guitar] | Saveur country |
| [orchestral strings] | Cordes cinématographiques |

## 4. Empiler les tags avec |

On peut combiner plusieurs instructions dans un même crochet :

- Solo rock années 80 : [guitar solo | 80s glam metal lead guitar | heavy distortion | wide stereo]
- Refrain pop moderne : [anthemic chorus | stacked harmonies | modern pop polish | bass drop]
- Couplet trap : [autotuned delivery | tuned male vocal | light reverb | stereo slapback]

## 5. Où placer les tags

Au **début de chaque section** des paroles, pas seulement dans le champ « Styles ».

Faux :

[Chorus]
We light it up like fire

Correct :

[Chorus | anthemic chorus | stacked harmonies | modern pop polish]
We light it up like fire

## 6. Recettes par genre

- **EDM** : [explosive drop | sidechained synth bass | riser | sub drop impact], [melodic hook | airy female vocal | reverb tail]
- **Country rock** : [spoken word verse | warm baritone | slight drawl], [anthemic chorus | pedal steel guitar | light snare reverb]
- **Pop punk** : [raspy lead vocal | youthful tone | light vocal grit], [bridge with drop | distorted power chords | bass slide-in]

## 7. Règles d'or

1. **Commence simple** : 2 ou 3 tags avant d'empiler.
2. **Reste cohérent avec le genre** : ne mélange pas [808 sub bass] et [pedal steel guitar], sauf fusion voulue.
3. **Superpose dans l'ordre** : élément de base → genre / époque → tonalité → effets.
4. **Ancre l'époque** : « 80s », « 60s », « modern » aident Suno à comprendre l'ambiance.
5. **Pas plus de 6 tags** par crochet, sinon Suno s'embrouille.
6. **Sois précis** : « 60s jangly guitar rhythm » plutôt que « guitar ».

## Exemple avant / après

Avant :

[Verse]
Walking down the street tonight
[Chorus]
I'm feeling so alive

Après :

[Verse | spoken word verse | warm baritone | light guitar strums]
Walking down the street tonight

[Chorus | anthemic chorus | stacked harmonies | driving kick-snare beat | bass drop]
I'm feeling so alive

**À retenir** : mets les tags à la fois dans le champ « Styles » ET dans les paroles pour un contrôle maximal.
